## 📚 Topics & Modules

### 1. Object-Oriented Programming (`oops/`)
Focuses on building robust, modular Python code using OOP pillars:
- **Classes & Objects**: Defining attributes (`__init__`) and methods.
- **Inheritance**: Creating child classes and extending functionalities.
- **Method Overriding**: Overriding parent class methods using `super()`.

### 2. OOP Assignments (`oopsAssignment/`)
Real-world practical scenarios:
- **Encapsulation**: Restricting direct data access with private variables (`__attribute`).
- **Polymorphism**: Common interfaces for different data types/classes.
- **Abstractions**: Base classes defining structural blueprints.

### 3. DSA & Logic Building
Foundational mathematical & algorithmic problems:
- Prime check, Binary-Decimal conversion, ASCII operations.
- Array operations, string manipulations, and basic search/sort logic.

### 4. Advanced & Frameworks
- **FastAPI**: REST API development.
- **NumPy**: High-performance multidimensional array processing.

## 🚀 How to Run the Code

### Prerequisites
Make sure you have **Python 3.x** installed.

```bash
python --version
```

### Running a Script

To run any script directly using Python:

```bash
python oops/bankAccount.py
```

### Running with Auto-Reload (`nodemon`)

If you have `nodemon` installed via Node.js, you can run files in live-reload mode while editing:

```bash
nodemon oops/bankAccount.py
```
