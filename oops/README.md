## 💡 Key Concepts Covered

1. **Classes & Objects (`class`, `__init__`)**:
   Defining blueprints and instantiating objects with state and behavior.

2. **Inheritance**:
   Extending base classes to reuse attributes and methods.

3. **Method Overriding & `super()`**:
   Replacing parent methods in derived classes while keeping access to parent functionality using `super().method_name(args)`.
